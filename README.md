# PayFlow

A simple USDC payment dApp built on Arc Testnet.

## What it does

- Connects an EVM wallet
- Switches/adds Arc Testnet
- Reads the wallet's USDC balance
- Sends USDC to another wallet
- Shows the transaction hash
- Links directly to Arcscan
- Uses Arc Testnet USDC for payment and gas

## Arc Testnet

- Chain ID: 5042002
- RPC: https://rpc.testnet.arc.network
- USDC: 0x3600000000000000000000000000000000000000
- Explorer: https://testnet.arcscan.app

## Tech

React + Vite + ethers.js

## Status

Testnet prototype. Testnet USDC has no real financial value.
